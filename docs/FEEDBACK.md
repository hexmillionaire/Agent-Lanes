# Try the connected workflow

We would like feedback from developers using Claude Code, Codex, or another MCP client. This is an invitation template; no developers have been contacted and no external feedback is claimed.

Try [the quickstart](QUICKSTART.md) on a small trusted repository. Create a task, make an allowed edit and an outside-scope edit, update notes in Desk, and compare the CLI/MCP handoffs. If you use Actions, try a development lane check on a documentation-only PR.

Open a **Workflow feedback** issue and tell us:

- What task and client were you using?
- How long did setup take, and where did you get stuck?
- Were scope warnings and the next handoff understandable?
- Which feature would make you keep using the tool?

Remove credentials, private notes, local paths, and transcripts before posting. We will prioritize reproducible feedback. The tools are tested by their developers; broader adoption remains unvalidated.
